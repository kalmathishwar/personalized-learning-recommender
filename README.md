# 📚 AI Learning Recommendation System

A personalized learning recommendation platform with intelligent course filtering and analytics dashboard.

## 🚀 Live Demo

**Deployed on Streamlit Cloud:** [Click here to view live app](#)

## ✨ Features

- 🎯 **Personalized Recommendations** - Smart filtering based on category, difficulty, and ratings
- 🔍 **Advanced Search** - Find courses by keywords instantly
- 📊 **Analytics Dashboard** - Visual insights into course distribution and trends
- 🎨 **Modern UI** - Clean, responsive interface built with Streamlit

## 💻 Tech Stack

- **Frontend:** Streamlit
- **Data Processing:** Pandas, NumPy
- **Deployment:** Streamlit Cloud

## 🛠️ Local Setup

```bash
# Clone repository
git clone https://github.com/YOUR-USERNAME/learning-recommendation-system.git

# Install dependencies
